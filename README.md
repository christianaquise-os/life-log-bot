# life-log-bot

A Telegram bot that logs your day in plain language. Message it, it figures
out what you mean, and it keeps a running tally of time spent per life
pillar (Nutrition & Body, Finance, Mind & Well-being, Relationships, Career &
Learning, Leisure).

## What to say to it

- **"I started doing laundry"** — starts an open-ended timer.
- **"I'm done"** / **"finished"** — closes whatever's running. If more than
  one thing is open, it'll ask which one; if nothing's open, it'll ask what
  you just finished.
- **"I've been doing this for 2 hours"** / **"read for 45 min"** — logs a
  completed activity directly, no timer needed.
- **"how did I do today"** or **/today** — get today's summary on demand.

Every evening (default 22:00, `Europe/Madrid`) it sends you an automatic
recap of the day.

## First-time setup

1. **Get a Telegram bot token.** Message [@BotFather](https://t.me/BotFather)
   on Telegram, send `/newbot`, follow the prompts. Copy the token it gives
   you.
2. **Find your Telegram chat ID.** Message your new bot once (anything),
   then check `https://api.telegram.org/bot<YOUR_TOKEN>/getUpdates` in a
   browser for `"chat":{"id": ...}` — or use a helper bot like
   [@userinfobot](https://t.me/userinfobot).
3. **Get an Anthropic API key** from
   [console.anthropic.com](https://console.anthropic.com/settings/keys).
4. Copy `.env.example` to `.env` and fill in the three values above.
5. Install and initialize:

   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   python scripts/init_db.py
   ```

6. Run it: `python main.py`. Message your bot on Telegram — you should get a
   reply within a couple seconds.
7. (Optional) Wire up the Notion mirror — see `CLAUDE.md` → *Why SQLite is
   authoritative*. Not required for the bot to work; it's a nice-to-have
   read-only view.
8. Once it's working manually, set up always-on running via `launchd`
   (Mac) or `systemd` (VPS) — templates in `deploy/`.

## Reading the daily digest

The nightly message (and `/today`) is generated by Claude from your actual
logged sessions — it won't invent activities you didn't log. If a day looks
wrong, the ground truth is always the SQLite database:

```bash
sqlite3 data/activity.db "select activity_name, pillar, duration_seconds, status from sessions order by id desc limit 20;"
```
